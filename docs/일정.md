## 다른 레포에 기대는 것
- **예약 코어 (지영):** 6자리 번호 발급과 `POST /api/access/verify`. 응답 형식, 장치 토큰, 5회 실패 잠금, 번호 유효 시간을 M1 안에 합의 (#5)
- **센서 이벤트 저장 위치:** core에 둘지 디바이스 서비스에 둘지 M1 안에 합의 (#5)
- **배포 (재웅):** 개발 서버 주소가 나오면 중계의 `SERVER`만 바꿔요
- **부품:** ESP32·레이더(LD2410C) 도착 전에는 우노 + 노트북 중계로 진행 (3차 회의)
